# 🎙️ VoiceFiller - Speak. Don’t Type.

**VoiceFiller** is a cross-browser extension that lets users fill forms using natural voice interaction.  
It converts speech to text, extracts answers using LLMs, and maps them automatically — inclusive, fast, and human.

## 🚀 Features
- Wake word: “Hey VoiceFiller”
- Multi-language support
- Story → Field extraction (LLM powered)
- Voice confirmation before submit
- Chrome, Firefox, Edge compatible

## 🧩 Tech Stack
HTML, CSS, JavaScript, Web Speech API, OpenAI GPT/Meta LLM via OpenRouter, jsPDF.

## 📦 Installation
1. Download the repo  
2. Go to `chrome://extensions/` → Turn on Developer Mode  
3. Click **Load Unpacked** → select this folder  
4. Say “Hey VoiceFiller!” and enjoy filling forms hands-free 🎧
